# Changelog

Все заметные изменения в этом проекте будут документированы в этом файле.

## [Unreleased]

### Добавлено
- Поддержка Laravel 12.x
- Поддержка PHP 8.2+
- Поддержка Carbon 3.x
- Обновлен PHPUnit до версии 10.x и 11.x
- Обновлен Orchestra Testbench до версий 7.x, 8.x, 9.x и 10.x

### Изменено
- Минимальная версия PHP повышена до 8.2
- Обновлен `phpunit.xml` для совместимости с PHPUnit 10+
- Обновлены зависимости для поддержки современных версий Laravel

### Удалено
- Удалена поддержка устаревших версий PHP (< 8.2)
- Удалена поддержка устаревших версий PHPUnit (< 10.0)
- Удалена поддержка устаревших версий Carbon (< 2.0)
- Удалена поддержка устаревших версий Orchestra Testbench (< 7.0)

## [4.2.0] - Предыдущая версия

### Исправлено
- Исправлена проблема с сохранением значений, содержащих нулевые байты, при использовании PostgreSQL
- Контент корзины теперь кодируется в base64 перед сохранением в базу данных при использовании PostgreSQL
