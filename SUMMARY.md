## Рекомендации для пользователей

### Для новых проектов
1. Установите пакет: `composer require bumbummen99/shoppingcart`
2. Опубликуйте конфигурацию (опционально)
3. Опубликуйте миграции (если нужно хранение в БД)
4. Используйте примеры из EXAMPLES.md

### Для существующих проектов
1. Обновите PHP до 8.2+ (если используете Laravel 11)
2. Обновите PHP до 8.3+ (если используете Laravel 12)
3. Выполните: `composer update bumbummen99/shoppingcart`
4. Очистите кэш: `php artisan config:clear && php artisan cache:clear`
5. Запустите тесты (если есть)

### Для разработчиков
1. Изучите TESTING.md для запуска тестов
2. Используйте EXAMPLES.md для современных подходов
3. Следуйте стандартам кодирования проекта
4. Убедитесь, что тесты проходят перед PR
